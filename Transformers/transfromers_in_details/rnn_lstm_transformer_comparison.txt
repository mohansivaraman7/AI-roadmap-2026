|                          |                            |                              | encoding                         |
+--------------------------+----------------------------+------------------------------+----------------------------------+

| longer                   |                            |                              | squared (n^2)                    |
+--------------------------+----------------------------+------------------------------+----------------------------------+
| Memory while generating  | Constant                   | Constant                     | Grows with length (stores past   |
|                          |                            |                              | keys and values)                 |
+--------------------------+----------------------------+------------------------------+----------------------------------+
| Parameters per layer     | Fewest                     | About 4x an RNN of the same  | Most (attention + feed-forward)  |
|                          |                            | size                         |                                  |
+--------------------------+----------------------------+------------------------------+----------------------------------+
| Scaling                  | Hard to make large         | Hard beyond a few layers     | Scales to billions of parameters |
+--------------------------+----------------------------+------------------------------+----------------------------------+

|                          |                            |                              | pre-training                     |

KEY POINTS
----------
1. The real breakthrough was PARALLEL TRAINING. Transformers train much faster on GPUs,
   which made models with billions of parameters possible.
2. Transformers are parallel while READING, but sequential while WRITING.
   ChatGPT and Claude still generate one token at a time.
3. It is a trade-off: RNN/LSTM are cheap per step but forgetful and slow to train;
   Transformers see everything directly but get expensive for very long inputs.
4. Each model fixed the previous one's problem:
   RNN (forgets)  ->  LSTM (adds gates to remember)  ->  Transformer (replaces recurrence with attention)
5. LSTMs are still useful for small datasets, sensor/time-series data and small devices.

ONE-LINE SUMMARY:
An RNN passes a note from word to word, an LSTM passes a better-organised note,
and a Transformer lets every word read every other word directly.
